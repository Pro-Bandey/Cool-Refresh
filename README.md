# Cool-Refresh

Customizable pull-to-refresh instead of the built-in one.


## Customize the look of your pull-to-refresh with colors, shapes, and more!

## Quick Setup After Install

1. Disable the built-in pull-to-refresh
    Menu (⋮) → Settings → Customize → (Scroll down and...) Uncheck "Pull to refresh"
2. Open Pretty Refresh settings
    Menu (⋮) → Settings → (Scroll down and...) Extensions → Pretty Refresh → Settings


## Settings Notes

- Changes apply instantly on the settings page.
- On other pages, refresh the page once to apply changes.

## Right now, there are just a few settings, but more features are on the way, such as:

- Adjustable size
- Position control
- Pull distance
- Refresh animations
- More templates
- Bottom pull-to-refresh
